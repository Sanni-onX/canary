# Canary demo

canary-protocol-demo.mp4 is a captioned protocol preview from the running
product: overview, simulated alarm/freeze/PQ rescue, and separate live Diana
evidence and finite-coverage limits. Local ML-DSA verification is real; asset
movement in the simulation is not. This is not a full Lifeboat walkthrough.
No actual user QoreX approval is represented by this recording.

Reproduce with `node scripts/record-demo.mjs`, then convert the printed WebM
path with FFmpeg. The script never imports personal wallet credentials.
Review the video and current chain state before submitting it publicly.

The original draft's Lifeboat sequence stopped at an unfilled rescue address;
that segment was excluded from this preview. The source recording script still
needs a completed migration sequence before generating a full submission demo.
